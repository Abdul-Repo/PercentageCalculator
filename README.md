## ✨ Features

*   **Real-Time Results:** No "Equals" button required. The app calculates as you type!
*   **Affect Value Toggle:** The magic switch. Instantly see your total after adding or subtracting the percentage.
*   **Neon UI:** A dark-mode-friendly interface that's easy on the eyes and looks great on any screen.
*   **Dual Mode:** Switch effortlessly between calculating the percentage of a total or finding the part value.
